# SABI — Wallpaper Visibility Adjustment

**Purpose:** Record the latest visual adjustment to the transparent SABI wallpaper.

**Previous update:** [respond3.md](./respond3.md)

## Change

The repeating vector wallpaper was too faint to notice in the light theme. Its opacity has been raised by two percentage points in each theme:

- Light: `0.8%` → `2.8%`
- Dark: `1.2%` → `3.2%`

The underlying page colors and the blue/yellow/white interface palette are unchanged. The wallpaper remains a static background texture behind page content.
